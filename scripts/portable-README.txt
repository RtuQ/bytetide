ByteTide · 字节潮 — 免安装版
================================

【运行】
双击 ByteTide.exe 即可运行，无需安装。

本程序依赖 WebView2 运行时（Windows 11 自带；Windows 10 大多数环境已随 Edge 安装）。
若启动提示缺少 WebView2，请到微软官网下载安装 Runtime（选 "Evergreen Standalone Installer"）：
https://developer.microsoft.com/microsoft-edge/webview2/

【升级到新版本】
1. 在 GitHub Releases 页下载最新版 ByteTide_x.y.z_x64-portable.zip
2. 解压后把 ByteTide.exe 覆盖到旧版所在目录（目录里的其他文件不要动）
3. 覆盖到原目录即可保留你的全部设置（主题、预设、搜索历史等）

提示：应用内标题栏右侧的版本号按钮可「检查更新」并直达下载页。
