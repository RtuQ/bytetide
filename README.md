# ByteTide · 字节潮

[简体中文](./README.md) | [English](./README.en.md)

一款给嵌入式开发者用的**串口 / 网络日志调试台**。设备通过串口、TCP 或 UDP 发来的每一行数据，你都可以在这里实时查看、搜索、画成波形，还能一键把日志"喂"给 AI 帮你分析协议。

> 为什么叫字节潮（ByteTide）？设备的日志像潮水一样涌来——这个工具就是你观潮、赶海的地方。原名 Serial Tool。

Tauri 2 + Vue 3 + Rust 构建：安装包小、启动快、内存占用低，完全离线运行，不依赖任何云服务。

---

## 它能帮你做什么？

- **调传感器 / 模组**：设备不停打印 `V: 220, C: 10, P: 200` 这样的数据？配置一下帧格式，立刻变成实时波形图，电压电流变化一眼看穿。
- **抓协议**：设备间的通信帧看不懂？让 AI 通过内置的 REST 桥直接读你的实时日志，帮你推断帧头帧尾、校验方式和字段含义。
- **盯异常**：给 `ERROR`、`ASSERT` 这类关键字设个告警规则，一旦出现立刻弹系统通知——挂机压测时不用盯着屏幕。
- **双板对比**：两块板子跑同一套流程，左右并排按时间对齐，行为差异自动标红。
- **事后分析**：日志自动落盘，事后打开 `.log` 文件就能离线复盘，功能一个不少。

## 3 分钟上手

1. **安装**（已发布则直接下载；从源码构建见[下文](#构建)）：
   ```bash
   npm install
   npm run tauri build   # 产物在 src-tauri/target/release/bundle/
   ```
2. **连接**：顶部选好端口（或 TCP / UDP 地址），点「连接」，日志开始滚动。
3. **开始用**：搜索框找关键字；点一行再按 `Ctrl+B` 加书签；侧栏「数据绘图」配好帧格式看波形；想让 AI 分析就打开「REST 桥接」。

> 手头没设备？仓库自带 [sample-data/plot-demo.log](./sample-data/plot-demo.log)（600 帧双通道正弦波），点「打开日志」载入即可体验全部功能。

## 功能一览

### 连接
- **多种数据源**：串口（COM）、TCP 客户端 / 服务端、UDP 监听，体验完全一致
- **多标签页**：同时开多个会话，互不干扰；配合「分屏」可同屏 2–4 列对比观察
- **连接可控**：停止（保留日志） / 重连（原配置恢复，日志、搜索、告警全带走） / 关闭
- **离线会话**：打开 `.log` 文件即为离线会话，除收发外全部功能可用（AI 桥也能读）
- 端口参数可存为**预设**一键套用

### 看日志
- 虚拟滚动，最多保留**最近 5 万行**，超长行横向滚动完整可读
- 随手开关：跟随尾部、只看命中、HEX 视图、行间时间差、行号 / 方向列
- 底部实时显示收发字节数与速率

### 找内容
- **搜索**：关键字或正则，命中列表就在搜索框下方，点击跳转
- **过滤链**：多条「包含 / 排除」条件串联，相当于可视化的 `grep | grep -v`
- **关键词高亮**：多个关键字各自配色、实时计数，与搜索互不影响

### 发送
- ASCII / HEX 双模式，`Ctrl+Enter` 发送，支持追加换行
- **定时循环发送**、发送历史点击回填

### 自动化
- **自动回复**：收到匹配内容自动回发，适合"查询-应答"式协议的自动化测试
- **告警**：关键字 / 正则命中即弹系统通知（可选提示音），支持次数聚合与冷却防刷屏，历史 100 条可点击回跳
- **行书签**：`Ctrl+F2` / `Ctrl+B` 标记关键行，侧栏列表管理
- **配置预设库**：过滤链 / 关键词 / 自动回复 / 帧格式四类配置命名保存，JSON 导入导出，团队共享

### 监控
- **实时仪表盘**：最近 60 秒行速率柱状图、字节速率曲线、行间隔 min/avg/p95/max

### 双会话对比
- 两路日志按时间轴 ± 容差配对，左右并排，差异高亮、超差标红、双向跳转

### 数据绘图
设备输出的字节流按帧切开，解析成多通道数值实时画波形。

帧格式自行配置：帧头 / 帧尾 / 校验（无、累加和、XOR）/ 通道数 / 每通道字节数（1/2/4）/ 大小端 / 有无符号。

```
[帧头][数据: 通道数 × 每通道字节数][校验字节?][帧尾?]
```

举例：帧 `01 00 01 02 12 43`，帧头 `01 00`，2 通道 × 2 字节，大端 →
通道 0 = `0x0102` = **258**，通道 1 = `0x1243` = **4675**。波形悬停任意点可看接收时间、原始帧与各通道值。

支持两种数据源：设备发紧凑二进制帧（原始字节模式），或发 `"01 00 12 43"` 这样的十六进制文本（ASCII hex 模式）。

### REST 分析桥（把日志交给 AI）

这是本工具最有意思的功能：在应用侧栏打开「REST 桥接」开关，它会启动一个**本机 HTTP 服务**（带令牌鉴权），外部程序——比如 AI CLI——就能直接读取你的实时日志。

工作流大概是：开关打开 → 把界面显示的 URL 和令牌复制给 AI → AI 就能：

- 分页读日志、实时等待新行（长轮询）、按关键字 / 正则 / 十六进制过滤
- 自动**推断帧格式**（帧头、校验方式），再按帧解码数值、做取值分布统计
- 分析收发节奏（直方图、间隔 p95、卡顿检测）
- 读你在界面里做的**书签和告警历史**——你标记过的地方就是 AI 该重点看的地方
- 把**完整的落盘历史**（不只内存里那 5 万行）流式导出
- 协议确认后，AI 可以把推断出的帧格式**一键写回**绘图面板，你在界面上立刻看到
- 需要时（默认关闭，需手动开启）还能代发命令并等待应答

配套的 AI 技能包在 [skills/serial-tool-bridge](./skills/serial-tool-bridge)（标准 SKILL.md 格式）：把该目录拷贝到你 AI 助手的技能目录即可安装——ZCode 用户放到 `~/.zcode/skills/`，Claude Code / Codex 等同理，开箱即用。

## 构建

```bash
npm install

npm run tauri dev      # 开发模式：桌面应用 + 热重载
npm run tauri build    # 打安装包，产物在 src-tauri/target/release/bundle/
npm run build          # 仅前端：类型检查 + 生产构建
npm test               # 前端单测（40+ 例）
cd src-tauri && cargo test   # 后端单测（30+ 例）
```

环境要求：Node.js 18+、Rust stable，以及 [Tauri 2 系统依赖](https://tauri.app/start/prerequisites/)。
GitHub Actions 会在 push / PR 时自动跑完整校验。

> 只跑 `npm run dev`（不开 Tauri 后端）也能看界面：空状态正常渲染，但收发等功能不可用。

## 项目结构

```
serial_tool/
├─ src/                  # 前端（Vue 3 + TypeScript + Pinia）
│  ├─ components/        # 界面组件：日志 / 发送 / 搜索 / 绘图 / 各侧栏面板
│  ├─ composables/       # 无界面逻辑：事件接入、解析器、绘图、告警音…
│  ├─ stores/            # 会话状态机、告警历史
│  └─ types/             # 类型与默认配置（单一事实来源）
├─ src-tauri/            # Rust 后端
│  └─ src/
│     ├─ bridge.rs       # REST 分析桥（axum）
│     ├─ serial/         # 串口 / 网络源读线程、环形缓冲
│     └─ …               # invoke 命令、日志落盘
├─ sample-data/          # 演示日志
├─ docs/                 # 截图等文档资源
├─ skills/               # REST 桥 AI 技能包（拷到 ~/.zcode/skills/ 即可安装）
└─ AGENTS.md             # 代码约定（改代码前必读）
```

## 路线图

1. **AI 分析入口**：在界面里直接对话式分析选中日志片段
2. **发送命令预设**：常用命令存成一键按钮
3. **发送自动补校验和**（累加和 / XOR / CRC16）
4. **绘图交互增强**：缩放、平移、双游标测量、导出 CSV / PNG
5. **内置协议模板**：Modbus RTU 等常见格式一键套用
6. **时序回放**：离线日志按原间隔重放成"伪实时"
7. 对比视图完整 diff、TCP 服务端多并发、UDP 指定对端发送
8. 全局快捷键 / 命令面板、串口别名备注
