# 演示数据源与截图指南

本地虚拟数据源 + 一步步的界面配置清单，用于给 README / 文档截取真实的界面图。
全部数据走本机 TCP 回环，不接真硬件、不装依赖。

```bash
node scripts/demo-feed.mjs
```

起两个本地 TCP 流（Ctrl+C 退出）：

| 流 | 地址 | 内容 | 用途 |
|---|---|---|---|
| ASCII 设备控制台 | `tcp://127.0.0.1:50101` | 多模块多级别遥测日志（ANSI 着色，含 WARN/ERROR 波动） | 日志视图 / 关键词高亮 / 查找 / 自动回复 / 告警 |
| 电源监控二进制帧 | `tcp://127.0.0.1:50102` | `AA 55` + 温度/电压/电流三通道 + 累加和，2Hz | HEX 视图 / 绘图 / 协议解码 |

客户端断线重连安全：接入即回填历史（ASCII 8 行、二进制 60 帧 ≈30s 波形），首屏不空。

---

## 一、ASCII 控制台流（日志类截图）

新建连接 → 数据源选 **TCP连接** → 主机 `127.0.0.1`、端口 `50101` → 连接。

日志格式：`[时:分:秒.毫秒] [级别] [模块] 内容`，级别 token 带 ANSI 色
（INFO 绿 / DEBUG 青 / WARN 黄 / ERROR 红），每 0.9s 一行，含温度/湿度/气压慢漂移。

**建议截图前配置：**

| 目的 | 配置 |
|---|---|
| 多色关键词高亮 | 侧栏 规则→关键词：`ERROR`、`WARN`、`温度`、`rssi`（调色板自动分配颜色） |
| 查找 | `Ctrl+F` 搜 `超时`，命中高亮 + 计数 |
| 告警规则 | 侧栏 规则→告警：匹配 `读取超时`（约 40s 触发一次），底部 dock「告警历史」攒条目 |
| 自动回复 | 侧栏 规则→自动回复：匹配 `复位完成` → 回复 `AT+SAMPLE=1\n`（TX 琥珀行出现在日志里） |
| 监控统计 | 侧栏 规则→关键词配好后，底部 dock「监控」看模块/级别命中趋势 |

## 二、电源监控帧流（HEX / 绘图 / 解码截图）

新建连接 → 数据源选 **TCP连接** → 主机 `127.0.0.1`、端口 `50102` → 连接。

帧布局（9 字节，一行一帧，2Hz，波形为多正弦叠加+噪声）：

```
AA 55 | 温度 i16BE ×0.1℃ | 电压 u16BE ×0.01V | 电流 u16BE ×0.001A | sum8
        └──────────── 6 字节数据段，sum8 仅覆盖此段 ────────────┘
```

**绘图（分屏/图表截图）：**

1. 工具栏开 HEX（绘图会自动强制 HEX 视图，二进制数据正常显示的前提）
2. 侧栏 数据→数据绘图：开绘图开关，配置
   数据源=`二进制`、帧头=`AA 55`、通道数=`3`、每通道字节=`2`、端序=`大端`、校验=`累加和`、帧尾空
3. 视图栏切「分屏」（日志+图表同屏）或「图表」（全幅波形）——上/中/下三条曲线即 温度/电压/电流

**协议解码（底部 dock「解码」截图）：**

1. 侧栏 规则→协议解析 → 导入 `sample-data/parser-power.js` → 启用（对已收日志自动回溯补解码）
2. 底部 dock 出现「解码」页签：每帧翻译为 `温度 26.4℃，电压 3.70V，电流 0.45A` 样式的结构化行
3. 试运行面板可先看三分类结果（0 帧不启用 / CRC 全败停留 / 通过自动启用）

**对比视图截图（同屏双会话）：**

两个流各开一个会话后，视图栏「对比」亮起 → 点击进入双会话时间对齐对比。

## 三、离线替代（不起数据源）

`sample-data/plot-demo.log`（`AA 55` 三通道正弦，TSV 录制格式）：「打开日志」载入后，
绘图配 数据源=`ASCII hex`、帧头=`AA 55`、通道数=`3`、每通道字节=`1`、校验=`无`。
适合静态波形截图，但无解码/告警等实时联动。

## 四、README 截图清单（建议）

1. **全局布局**：双会话 + 侧栏 + 状态栏（最能体现信息密度）
2. **日志视图**：ASCII 流 + 关键词多色高亮
3. **分屏**：HEX 日志 ↔ 实时三通道波形同屏
4. **解码 dock**：电源监控解码行 + 字段徽章
5. **告警历史**：ERROR 触发的告警条目
6. **对比视图**：双会话时间对齐

截图后放 `docs/`（或按 README 现有引用路径），更新 `README.md` / `README.en.md` 的预览图段落。
