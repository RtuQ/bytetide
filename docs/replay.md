# 时序回放（Replay）用户指南

回放把一份离线录制日志按**相邻行原始时间差**重放为伪实时会话：行按原顺序、
原时间戳进入会话的 ring，速度可调（0.1x–100x）、可循环、可跳转。回放不是
「打开一份离线文件」，而是一条有生命的会话——解析、绘图、搜索、告警、对比与
只读场景自动化都在实时数据流上工作。

## 1. 概念

- **游标拉模型**：回放行只进 ring（后端唯一真相），前端按 `no` 游标周期性拉取
  增量——与实时会话同一条数据通路，无并行模拟。
- **`IngestOrigin::Replay` 隔离**：告警规则照常逐行评估并稀疏上报；自动回复、
  现场捕获落盘被结构性排除（回放不与历史设备对话、不产生新档案）。
- **gap 钳制**：相邻行原始时间差 Δ 先钳到 `max_gap_ms`（V1 固定 10 秒）再除以
  速度——实际睡眠 = min(Δ, 10s) / speed，恒 ≤ 10s/speed。长空闲不会卡住回放，
  行的原始时间戳保持不变（钳制只作用于睡眠）。
- **ring 语义**：seek 与 loop 回卷都清空 ring 但 `no` 序列不回退（单调递增）；
  RING_CAP = 100,000 行/会话。

## 2. 打开与控件

入口：TabBar「＋」→ 打开日志 → 选择「回放」方式（或「数据 → 现场捕获」档案
的回放入口）。打开后返回 `{sessionId, lineCount, durationMs}`（时长=首末行原始
epoch 差，回放工具条的总行数/时长来源）。

回放工具条（仅回放会话显示）：

| 控件 | 行为 |
|---|---|
| 播放 / 暂停 | 暂停立即停住；恢复从当下重算下一行完整延迟（不补偿暂停期迟到，无爆发追赶） |
| 停止 | 置 Stopped；会话保留可再次 seek 复活 |
| 速度 | 0.1–100（非法值在打开时执行前拒绝；运行中调速把在途等待按比例重标定） |
| 循环 | EOF 后清 ring 回到行 1 继续 |
| 进度 / seek | 当前文件行水位 / 总行数；seek(n) 清 ring 直达第 n 行，下一行立即入库；拖动结束才发命令（防 IPC 洪水） |

状态机：`ready → running ⇄ paused`；EOF 未循环 → `finished`（seek 可复活）；
停止/断开 → `stopped`；源文件读失败 → `error`。状态变化发稀疏事件
（`replay-state`），不逐行发事件。

## 3. 行为矩阵

| 功能 | 回放会话 |
|---|---|
| 解析器（协议解码） | ✅（解码行入 dock「解码」页签） |
| 图表（plot） | ✅ |
| 搜索 / 关键词 / 过滤 | ✅ |
| 告警（规则评估 + 历史） | ✅ |
| 书签 / AI 笔记 | ✅ |
| 对比视图 | ✅ |
| 场景自动化（只读：wait/assert/delay/repeat） | ✅ |
| 场景自动化（含 send/signal） | ❌「回放会话不支持发送步骤」 |
| 发送 / 快捷帧 / 序列 | ❌「回放会话不支持发送」 |
| DTR/RTS 信号线 | ❌「回放会话不支持信号线」 |
| 录制 / 分段 | ❌「回放会话不支持落盘」 |
| 现场捕获（触发式落盘） | ❌（Replay origin 结构性排除） |
| 自动回复 | ❌（同上） |
| 清屏 | ✅（清 ring，不动回放游标；seek 后按序重灌） |
| 重连 | ❌（回放会话无链路；重新打开即可） |

## 4. gap 钳制语义（示例）

日志片段：`00:00:00.350` 之后一条 `00:00:25.000`（Δ=24.65s）。

| speed | 实际睡眠 |
|---|---|
| 1x | min(24650, 10000) / 1 = 10s |
| 10x | 1s |
| 100x | 0.1s |

行进入 ring 后仍携带原 ts（`00:00:25.000`）——「历史的时间、实时的流」。

## 5. 稳定性（soak）

- ring 恒 ≤ 100,000 行；`no` 全程单调无重复（seek/loop 清屏不回退游标）。
- CI 常驻快版 soak：`cargo test -p bytetide-core --test replay_soak -- --ignored`
  （虚拟时钟等效，秒级验证上限与游标纪律）；一键脚本
  `node scripts/soak-replay.mjs`（默认 quick；`--real --duration-min 30` 在本地
  跑真实 30 分钟 100x 定速循环并采样 RSS，输出 JSON 摘要：
  durationMs / producedLines / maxRingLines / completedLoops / errors[]）。

## 6. 常见问题

- **回放比实时日志「快」或「慢」？** 检查速度设置；日志行间隔本身不均匀时
  gap 钳制会把超 10s 的空闲压到 10s/speed。
- **seek 之后行号为什么变了？** ring 清屏后 `no` 从断点续（不回退），视图行号
  是 ring `no`；文件行号以工具条水位为准。
- **为什么不能发送？** 回放是历史的伪实时呈现，不与设备对话——发送/信号线/
  录制/捕获都被守卫拒绝（文案见行为矩阵）。需要与设备交互请用实时会话 +
  场景自动化。
- **告警为什么不触发？** 确认侧栏告警规则已启用且随连接推送（回放会话同样走
  `set_live_rules`）；规则在行入库后修改不回溯已评估的行（seek 重播可复现）。
- **回放会话能跑自动化吗？** 只读场景（wait/assert/delay/repeat）可以——
  适合对历史日志做回归校验；含 send/signal 的场景会被拒绝。
- **日志文件格式？** TSV `ts<TAB>dir<TAB>text`（`#` 注释与空行跳过）；二进制
  原始字节不落盘（lossy 文本），HEX 直发等字节语义仅实时行具备。
